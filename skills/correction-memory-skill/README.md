# correction-memory-skill

自动沉淀和复用“纠错经验”的技能。

该技能用于把“被用户纠正过的问题”沉淀为可检索、可合并、可迭代的经验库。目标是减少重复犯错：遇到新问题时先找相似历史，纠正后再把新经验写回。

## 能力概览

- 提供基于本地文件系统（`/data/userdata/correction-memory/`）的纠错经验持久化存储
- 支持案例结构化：记录问题模式、症状、根因、修正规则、反模式和成功示例
- 自动相似案例合并与统计（`hit_count`）
- 提供配套 Python 脚本实现经验的搜索（`search_cases.py`）与更新（`upsert_case.py`）

## 适用场景

- 用户指出回答、代码、流程、文件生成或工具使用中的问题并给出纠正意见时
- 遇到报错、返工、用户说“不对/不是这样/应该/改成/刚才错了”等场景
- 开始一个可能重复踩坑的复杂任务前，预先检索历史经验
- 用户要求“记录类似问题”或“自动迭代”

## 不建议使用的场景

- 一次性常识问答，没有纠错、返工或错误风险
- 用户明确要求“不要记录”或“临时处理，不作为规则”
- 内容包含敏感凭证、个人隐私或不应持久化的信息（仅记录脱敏抽象模式）
