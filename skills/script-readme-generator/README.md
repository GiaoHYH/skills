# script-readme-generator

脚本 README 自动生成器技能。

规定了每次生成脚本时，自动在脚本所在文件夹下同步生成一个标准化的 `README.md` 说明文件，帮助开发者更好地记录和理解生成的脚本。

## 能力概览

- 规范化脚本生成流程与代码风格（内置依赖加载、相对路径处理等）
- 强制要求自动生成配套的 `README.md` 文件
- 提供了标准的 `README.md` 模板，包括功能、依赖、数据文件、使用方式和输出示例等必要章节

## 适用场景

- 要求"生成脚本"、"创建脚本"、"写一个脚本"、"新建脚本"等
- 要求创建 `.js`、`.ts`、`.py`、`.sh` 等可执行文件
- 在对话中描述自动化任务，需要通过脚本完成时

## 不建议使用的场景

- 只是修改已有脚本的局部代码
- 只是询问脚本相关问题，不涉及创建新文件

## 文件说明

- `SKILL.md`: 技能主定义文件，包含完整的生成流程规范与模板
- `README.md`: 本技能的展示说明文件
